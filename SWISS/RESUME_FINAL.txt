================================================================================
UIC CODE MAPPING
================================================================================

Format: 85XYZZZ (7 digits)
  85: Switzerland country code
  X: Stop type/category
  Y: Regional identifier
  ZZZ: Station number

Examples:
  8507000 = Zurich HB (Hauptbahnhof)
  8500010 = Geneva Cornavin
  8503000 = Bern
  8505000 = Lausanne
  8502113 = Brig
  8509000 = Chur

Integration:
  stops.txt (stop_id) = UIC code
  → Match with stations.csv (uic column)
  → Automatic station identification
  → No manual mapping needed
